# 기능 요구 사항

### 입력 기능

1. 자동차 이름 입력 기능

- 최소 두대 이상의 자동차 이름을 작성해야 한다.
- 각 자동차의 이름의 길이는 1자 이상 5자 이하여야 하며, 공백은 허용되지 않는다.
- 각 자동차의 구분은 쉼표(,)로 한다.

2. 자동차 시도 횟수 입력 기능

- 숫자만 입력해야 한다.
- 최소 1번 이상을 입력해야 한다.

### 자동차 운행 기능

- 자동차는 전진 또는 멈춤을 한다.
- 전진하는 조건은 Console API의 Random.pickNumberInRange() 를 사용하여 랜덤값으로 판별한다. 랜덤값은 0 ~ 9 를 받을 수 있는데, 4 이상일 경우에만 전진한다.

### 출력 기능

- 각 시도별로 결과를 출력 하며, 이전 출력 결과에 더한다.
- 자동차가가 전진할 경우에는 - 로 표시를 하며, 멈춤일 경우에는 아무 표시를 나타내지 않는다.
- 전진을 가장 많이 한 자동차가 우승이며, 우승자는 한 명 이상일 수 있다. 여러 명의 우승자가 있을 경우 쉼표(,)를 이용하여 구분한다.

# 예외 처리

### 자동차 입력 예외 처리

- 자동차의 이름 갯수가 2~100개 사이가 아닌경우
- 자동차 이름 길이가 5자 초과나 공백인 경우
- 자동차 이름 입력시 이름 사이에 공백에 있는 경우 (ex: y una)
- 자동차 이름이 중복된 경우
- 자동차의 구분을 쉼표(,) 가 아닌 다른 문자열인 경우

### 자동차 시도 횟수 예회처리

- 숫자외에 다른 문자열인 경우
- 숫자 입력시 횟수가 0인경우
- 시도횟수가 1 ~ 100 사이가 아닌경우

| 테스트 목적                                          | 입력값 (예시)                                             | 예상 에러 메시지                                                      |
| ---------------------------------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------- |
| **빈 문자열 입력 시 예외 처리 (자동차 이름)**        | `['', '1']`, `['       ', '1']`                           | `[ERROR] 빈 문자열은 허용이 안됩니다.`                                |
| **자동차 이름 길이 제한 (1~5자) 위반 시 예외 처리**  | `['abc,abcdefgh', '1']`, `['abcdefgh,abc', '1']`          | `[ERROR] 자동차 이름은 1글자이상 5글자 이하로 작성해야합니다.`        |
| **자동차 이름에 공백이 포함된 경우 예외 처리**       | `['abc,abce   fgg', '1']`                                 | `[ERROR] 자동차 이름에 공백은 허용이 안됩니다.`                       |
| **자동차 이름 개수 제한 (2~10개) 위반 시 예외 처리** | `['car', '1']`, `['car@', '1']`, `['abc,', '1']`          | `[ERROR] 자동차이름 갯수는 최소 2개 이상 10개이하로 작성해야 합니다.` |
| **자동차 이름 중복 입력 시 예외 처리**               | `['car,car', '1']`, `['car,yuna,car', '1']`               | `[ERROR] 자동차 이름은 중복될 수 없습니다.`                           |
| **빈 문자열 입력 시 예외 처리 (시도 횟수)**          | `['car1,car2', '']`, `['car1,car2', '        ']`          | `[ERROR] 빈 문자열은 허용이 안됩니다.`                                |
| **시도 횟수 숫자 타입이 아닐 경우 예외 처리**        | `['car1,car2', ',']`, `['car1,car2', 'abc']`              | `[ERROR] 시도 횟수는 숫자 타입만 허용이 됩니다.`                      |
| **시도 횟수가 범위(1~100) 벗어날 경우 예외 처리**    | `['car1,car2', '0']`, `['car1,car2', '9007199254740991']` | `[ERROR] 시도 횟수는 1번 이상으로 100번 이하로 작성해야 합니다.`      |
